# 研究计划：答对了题，却不是同一个学生——LLM 模拟学习者的认知诊断保真度

Oct 30, 2026 · @Gavin

## 摘要

本研究要检验一个论断：**LLM 模拟学生可以复现真实学生的分数，却未必复现产生这些分数的认知结构；能服从认知人设，也不等于像真实学生。**

方法上，以认知诊断模型（CDM）为标尺，从三个维度评估 LLM 模拟学生：群体结构保真、条件可控性、错误机制保真。对照对象包括独立采样、高斯 copula、IRT 生成、CDM 生成等基线，以及真人留出数据。

第一版用 FrcSub 做试点，再加一个更大的真实作答数据集，目标是 EDM 2027 或 AIED 2027 的 full paper。扩展版投 IEEE TLT（SCI）或中文 CSSCI 期刊。正式实验前设三道 pilot 关卡，任何一道不过都要先调整设计。

## 研究背景与问题提出

用 LLM 模拟学生的研究增长很快，用途包括题目预试与难度估计、测试自适应学习系统、教师培训和数据增广。但对模拟质量的评估大多停留在聚合层，例如题目难度相关、正确率分布是否接近。

近期有两项证据说明聚合层吻合并不可靠。Kumagae & Kaneko（2026）在社会调查场景中发现，六个 LLM 生成的合成总体在个体覆盖上全部输给"按边际分布独立采样"的基线。Tohoku 团队的 EMNLP 2026 论文发现，加入学习者画像会改善个体层模拟，却常常损害群体层一致性。

教育场景的问题更具体。学生的分数由技能掌握结构产生，同样的总分可以来自完全不同的掌握模式，而诊断与补救依赖的正是这个结构。如果模拟学生只对得上分数，用它来设计诊断题、校准题库或测试自适应系统，都可能得出误导性结论。

因此本研究的核心问题是：**边际吻合能否推出认知结构吻合**？认知诊断模型给出了检验这个问题的现成标尺：Q 矩阵规定了每道题需要哪些属性，掌握模式规定了每个学生会什么，slip/guess 参数刻画了真人作答中的随机性。

## 相关工作与差异化定位

本研究的位置是：**用教育测量自家的认知诊断工具，检验 LLM 模拟学生在结构层面是否保真**。下表中的每项工作都只覆盖了其中一部分。

| 工作 | 做了什么 | 没做什么（本研究补位） |
| --- | --- | --- |
| [Kumagae & Kaneko, 2026](https://arxiv.org/abs/2610.30900) | 提出 respondent coverage gap，证明合成调查总体的个体覆盖输给边际独立采样基线 | 限于社会调查；不问错误结构从哪来；不涉及技能掌握结构 |
| [Tohoku NLP 等, EMNLP 2026](https://arxiv.org/abs/2609.35376) | 在真实学习者数据上，发现画像改善个体层模拟但损害群体层一致性 | 评估的是学习者对反馈的评价，不是作答的认知结构 |
| [Arda 等, SkillEval, 2026](https://arxiv.org/abs/2610.28767) | 把 CDM 用于给 LLM 当被试做分技能画像 | 方向相反：它诊断 LLM 本身，本研究用 CDM 诊断 LLM 扮演的学生 |
| Lu & Wang, Generative Students, L@S 2024（待核实） | 用知识组件画像让 LLM 模拟学生，用于题目评估 | 待精读确认；预计未以 CDM 结构、slip/guess、跨题错误一致性为标尺 |
| LLM 模拟错误概念学生的相关工作（待检索） | 待检索 | 需确认是否已有跨题一致性评估 |

## 研究问题与假设

三个研究问题中，RQ1 是主问题，RQ2 是次问题，RQ3 是条件性问题：只有拿到学生级、跨题、含具体干扰项选择的真实数据才纳入。

**RQ1（群体结构保真）**：LLM 模拟学生在边际层面与真实学生吻合时，题目间依赖结构和认知诊断结构是否也吻合？

- H1：LLM 的题目通过率与真人高度相关，但题目间依赖结构、CDM 参数与留出真人数据的差距超出抽样噪声范围，且不优于 IRT 或 CDM 生成基线。

**RQ2（条件可控性及其与保真度的关系）**：给 LLM 指定属性掌握模式后，它能否按该模式作答？可控性提高时，保真度是否随之提高？

- H2：属性人设下的回读一致率较高，但隐含 slip/guess 显著低于真人估计值，即生成"过度理想化的学生"，结构保真不升反降。
- H3：存在能力泄漏，即被设定为未掌握某属性时，需要该属性的题目上的正确率显著高于真人 guess 参数所预期的水平。

**RQ3（错误机制保真，条件性）**：LLM 模拟学生的错误是否像真人一样，稳定地对应特定错误概念？

- H4：无状态生成时，错误概念的跨题一致性低于真人；有状态生成时一致性上升，但在"错配历史"对照下同样上升，说明一致性来自对上下文的模仿而非稳定的认知结构。

所有假设都设计成正反结果皆可报告，但"不显著"不等于"等效"。只有当主要指标的效应估计及其置信区间都落在预先设定的等效界值内，才能说"结构与真人相当"；否则只能说"未发现超出抽样噪声的差异"。主要指标与等效界值见分析计划。

## 三维评估框架与指标

框架由三个并列维度组成，核心解读规则是：**可控性高而结构保真低，等于"听话但不像人"**，两者必须分开报告。

| 维度 | 回答的问题 | 主要指标 | 解读注意 |
| --- | --- | --- | --- |
| A1 群体结构：边际 | 难度与总分分布像不像 | 题目通过率的相关与 RMSE；总分分布的 Wasserstein 距离 | 必要但不充分，只作起点 |
| A2 群体结构：依赖 | 题目之间怎么相关 | **RQ1 主要指标**：题目间四分相关矩阵与留出真人数据的逐元素 RMSE。辅助指标：在合成数据上拟合、在留出真人数据上预测的对数似然 | 不依赖 CDM，避免循环评价；小样本下对极端题目的四分相关做平滑处理 |
| A3 群体结构：CDM | 认知诊断结构像不像 | DINA 与 G-DINA 下的 slip/guess 分布、属性掌握率、掌握模式分布距离、绝对拟合 | 用 CDM 评价 CDM 生成基线有循环性，只作辅证 |
| A4 描述性指标 | 作答组合层面像不像 | 完整作答模式分布的总变差距离；仿 RCG 的最近邻覆盖；平行分析的维度数 | 20 题有 2^20 种作答模式，约 268 人的样本极度稀疏，只作描述，不作推断 |
| B 条件可控性 | 指定 α 后能否按 α 作答 | 属性层与模式层回读一致率；DINA 下的隐含 slip/guess；同一人设重复生成的作答变异 | 与可达天花板比，而不是与 100% 比 |
| C 错误机制 | 错误是否对应稳定的错误概念 | 干扰项选择分布的 JS 散度；共享同一错误概念的题对上的条件一致性；错误可被错误概念标签解释的比例 | 仅在有学生级干扰项数据时纳入 |

维度 B 统一在 DINA 下定义。DINA 的非补偿式理想作答给出了清晰的"应会/不应会"划分，FrcSub 也是 DINA 的经典应用数据。设学生的指定掌握模式为 α，题目 j 的 Q 矩阵行为 q\_j，DINA 理想作答为 η\_j：

```latex
\eta_j = \prod_{k} \alpha_k^{q_{jk}}, \qquad \hat{s}_j = P(X_j = 0 \mid \eta_j = 1), \qquad \hat{g}_j = P(X_j = 1 \mid \eta_j = 0)
```

隐含 slip 低于真人估计说明"过度理想化"，隐含 guess 高于真人估计说明能力泄漏，比较对象都是真人数据上估计出的 DINA slip/guess 参数。

若关卡 1 显示 DINA 拟合明显劣于 G-DINA，则改用 G-DINA：以各题的条件正确概率 P(X\_j = 1 | α) 代替 η\_j，把隐含 slip/guess 推广为 LLM 正确率与模型预测正确率之差。这一选择在正式生成前做出，并写入预注册。

**可达天花板**的算法是：用真人数据拟合的 DINA 参数（或关卡 1 选定的模型），对同一批指定 α 模拟作答，再诊断回 α̂，得到真实随机性水平下理论上能回读到的一致率。LLM 的回读率只有放在这个天花板旁边才能解读：远高于天花板同样是问题，说明它太确定。

## 数据

第二数据集要支撑维度 B，必须**四项齐备**：学生级作答、题目原文、可用许可、可信的 Q 矩阵。只有前三项时，只能支撑维度 A1、A2。很多经典 CDM 数据集（例如 ECPE）只公开作答矩阵，没有题目原文，因此用不了。

| 数据集 | 规模 | 用途 | 状态与风险 |
| --- | --- | --- | --- |
| FrcSub（Tatsuoka 分数减法） | 536 人 × 20 题 × 8 属性，带专家 Q 矩阵 | 试点与方法演示；维度 A、B | R 的 CDM/GDINA 包内置；题目原文需从原始文献核对；题目对 LLM 过于简单，能力泄漏风险高 |
| Eedi NeurIPS 2020 Education Challenge | 大规模学生级作答，含所选选项（待核实） | 第二数据集候选；有可信 Q 矩阵时支撑维度 A、B，否则只支撑 A1、A2 | 学科标签不等于认知属性：若由标签构建 Q 矩阵，需专家审核，并对 Q 矩阵的不同设定做敏感性分析；字段、许可、题目原文可得性待核实 |
| Eedi Kaggle 2024 错误概念数据 | 题目、选项及干扰项对应的错误概念 | 只用作错误概念分类体系和标注参考 | 无学生作答，**不能**作真人对照，也不能单独支撑 RQ3 |
| 国内学生数据（若可获得） | 待定 | 期刊扩展版；提升中文期刊发表价值 | 需伦理审批与数据协议；同样需要可信的 Q 矩阵 |

**防污染措施**：FrcSub 是公开数据，LLM 可能见过原题。为每道题编写同构改写题，替换数字但保持属性需求不变（分数减法很容易做到），比较原题与改写题上的作答差异。这一步同时可以检验 Q 矩阵在改写题上是否仍然成立。

**数据切分**：真人数据随机分为拟合半与留出半。拟合半用于估计基线参数和人设分布，所有保真度比较都以留出半为参照。整个切分重复 B 次，以吸收切分本身的随机性。

## 实验设计

核心设计为 3（人设）× 2（状态）× 2（解码）× 3（模型），共 36 个单元，全部在原题上运行；同构改写题只在主结果最关键的单元上补跑。

### 实验因素

| 因素 | 水平 | 为什么必须控制 |
| --- | --- | --- |
| 人设 | 无人设；能力人设（按真人 θ 分布分档描述）；属性掌握人设（逐条用自然语言说明每个属性掌握与否） | 区分"给分数线索"与"给认知结构线索"的效果；暂不加人口学人设 |
| 状态 | 无状态（人设 + 当前题）；有状态（人设 + 当前题 + 该虚拟学生此前作答） | 跨题一致性可能来自对历史答案的模仿；有状态条件下题目顺序按拉丁方随机平衡，并记录上下文长度，避免历史效应与题目顺序、上下文长度混淆 |
| 解码 | temperature 0；temperature 1 | 解码设置是影响作答变异与隐含 slip/guess 的实验因素；不预设任何温度能匹配真人随机性 |
| 模型 | 两个开源模型（不同家族或规模）+ 一个闭源前沿模型 | 具体版本在 pilot 时锁定，记录版本号与调用日期；推理型模型的推理设置固定并记录 |
| 题目版本 | 原题；同构改写题 | 检验污染与记忆，仅在关键单元补跑 |

RQ3 若纳入，额外加一个**错配历史**对照：给模型看另一个虚拟学生的作答历史。如果一致性在错配条件下同样上升，说明它来自对上下文的模仿。

### 虚拟学生的生成

人设不是随意设定的，而是从真人数据中抽取：属性人设的 α 从拟合半的掌握模式后验分布中抽样，能力人设的 θ 从拟合半的能力估计分布中抽样。这样合成总体与真实班级的构成一致，比较才公平。每个单元生成与留出半同等数量的虚拟学生，同一人设重复生成 R 次，用于估计作答的随机性。

提示要求模型"以该学生的身份作答，包括这个学生可能犯的错误"。输出格式为**先给最终答案、再补演算过程**，避免先写出完整演算、把答案算对，从而加剧能力泄漏。计分只用最终答案，演算过程保存下来供错误分析使用。

以 FrcSub 粗算，每个单元约 268 名虚拟学生 × 20 题 ≈ 5,400 次调用，12 个单元 × 1 个模型约 6.4 万次。开源模型可以本地全量运行；闭源模型若预算有限，只跑 pilot 后确定的最关键 4 个单元。

## 基线

| 参照 | 保留了什么 | 角色 |
| --- | --- | --- |
| 真人 split-half（重复 B 次） | 真实数据本身 | 抽样噪声参照：判断多大差异才超出噪声 |
| 独立 Bernoulli 采样 | 只有题目通过率 | 弱基线 |
| 高斯 copula | 通过率 + 两两相关 | 弱基线 |
| 2PL IRT 生成 | 单维能力结构 | 强生成基线 |
| CDM 生成（与关卡 1 选定的模型一致） | 认知诊断结构 | 强生成基线（用 CDM 指标评它有循环性） |
| 留出真人数据 | — | 所有比较的外部检验集 |

所有基线都只在拟合半上估计参数。如果 LLM 连独立 Bernoulli 基线都赢不了，这本身就是一个可报告的主结果，与 Kumagae & Kaneko 的发现形成教育场景的对应。

## Pilot 研究与关卡

正式生成前先做一个约一周的小规模 pilot：一个开源模型、约 100 名虚拟学生、无人设与属性人设两个条件、只用 FrcSub。**三道方法关卡和一道数据关卡全部通过后才进入正式实验**。

表中数值为**暂定值**，必须在运行 pilot 之前锁定并记录，不能看到结果后再调。G-DINA 类模型没有通用的拟合阈值，这些数值是本研究自己的决策规则，论文中需如实说明。

| 关卡 | 检验什么 | 通过标准（暂定，pilot 前锁定） | 不通过怎么办 |
| --- | --- | --- | --- |
| 1. 真人 CDM 拟合 | DINA 与 G-DINA 在真人数据上是否拟合可靠；维度 B 用哪个模型 | SRMSR ≤ 0.05（常用参考值），题目对检验经多重校正后无大面积显著；每个属性的分类准确性 ≥ 0.80；DINA 相对 G-DINA 的拟合损失不显著时，维度 B 用 DINA | 换用文献中其他版本的 Q 矩阵或合并属性；维度 B 改用 G-DINA |
| 2. 个体分类误差 | 可达天花板有多高 | 每个属性的回读天花板 ≥ 0.80；模式层回读天花板 ≥ 0.50 | 属性层不达标的属性不进入维度 B 分析；模式层不达标则放弃模式层回读一致率，只报属性层 |
| 3. 能力泄漏 | 属性人设下，η\_j = 0 题目上的正确率（泄漏率） | 至少一种提示策略下，泄漏率比真人 guess 均值高出不超过 0.30 | 依次尝试先答后解释、给出错误示例等策略；所有策略都超标时，把"能力泄漏的度量与成因"升为主结果，重写论文重心 |
| 4. 数据（与 pilot 并行） | 第二数据集的学生级作答、题目原文、许可、可信 Q 矩阵 | 四项齐备：支撑维度 A、B | 仅前三项：只做 A1、A2；无学生级干扰项作答：砍掉 RQ3；都没有：以 FrcSub 加改写题为主，如实说明局限 |

关卡 3 最可能出问题：分数减法对任何现代 LLM 都是送分题，被设定为"不会借位"的模拟学生很可能照样算对。所以 pilot 第一件事就测它。

## 分析计划

RQ1 只用一个主要指标做推断：**题目间四分相关矩阵与留出真人数据的逐元素 RMSE**。等效界值 Δ 取真人 split-half 在同一指标上差距分布的 95% 分位，判定分三档。

| 判定 | 条件（LLM 条件指标的 90% 置信区间） | 可以下的结论 |
| --- | --- | --- |
| 超出噪声 | 下界 > Δ | 结构与真人存在超出抽样噪声的差异 |
| 与真人相当 | 上界 ≤ Δ（等效检验） | 在该指标上，结构与真人相当 |
| 不确定 | 两者都不满足 | 只能说"未发现超出抽样噪声的差异"，不能说已复现结构 |

1. **噪声参照**：真人数据重复 B 次（如 200 次）随机对半切分，计算每个指标在两半之间的差距，形成噪声分布，并据此确定 Δ。
2. **主分析**：主要指标按上表三档判定。其他指标按"条件 × 模型"报告 bootstrap 95% 置信区间，作为辅助或描述证据，与各基线并列呈现。
3. **因素效应**：对逐题作答、回读正确与否、隐含 slip/guess 等二元结果，拟合混合效应 logistic 回归。固定效应为人设、状态、解码、模型及其主要交互；随机效应为虚拟学生和题目。
4. **循环性与稀疏性控制**：CDM 指标（A3）只作辅证；完整作答模式分布、RCG 覆盖和平行分析维度数（A4）只作描述，不作推断。
5. **多重比较**：主假设 H1–H4 用 Holm 校正，探索性分析明确标注。
6. **预注册**：pilot 前锁定关卡数值；正式生成前在 OSF 预注册假设、主要指标、Δ 的计算方式，以及维度 B 采用 DINA 还是 G-DINA。

**复现材料**：公开全部提示模板、解码参数、模型版本与调用日期、原始输出和分析代码。估计工具为 R 的 GDINA 与 CDM 包，生成与评分用 Python。

## 预期贡献

- **概念贡献**：把"保真度"与"可控性"明确区分，指出高回读一致率本身不是保真证据，并给出可达天花板这一解读基准。
- **方法贡献**：一个三维评估框架及配套指标，附带噪声参照与强弱基线体系，可直接复用于其他模拟学习者研究。
- **实证贡献**：在教育场景中，以认知诊断结构为标尺，系统检验 LLM 模拟学生的保真度、能力泄漏和解码设置的影响。
- **实践贡献**：一份模拟学习者研究的最低报告清单，包括必须报告解码参数、状态设置、与噪声参照的比较等。

## 风险与应对

| 风险 | 可能性 | 应对 |
| --- | --- | --- |
| 能力泄漏严重，LLM 模拟不出低水平学生 | 高 | pilot 第一项就测；无法缓解时把泄漏本身升为主结果 |
| 撞题：已有工作用 CDM 评估过模拟学生 | 中 | 11 月上旬完成文献核查；若撞题，收窄到可控性与保真度的张力或能力泄漏 |
| 找不到第二个合格数据集 | 中 | 以 FrcSub 加改写题为主，砍掉 RQ3，在局限部分如实说明 |
| 审稿人质疑 FrcSub 太老、太简单 | 中 | 主动讨论，并用改写题和第二数据集回应；强调它是 CDM 领域的标准基准 |
| 数据污染 | 中 | 同构改写题对照 |
| 闭源模型版本在实验期间更新 | 中 | 锁定版本号，集中在短时间内完成调用并记录日期 |
| 时间不足以赶上首个截稿 | 中 | 首投改为截稿更晚的会议；pilot 不过关时不硬赶 |
